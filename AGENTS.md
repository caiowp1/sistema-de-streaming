# Orientações do projeto

- Leia README.md, ROTEIRO.md e STATUS.md antes de iniciar uma etapa.
- Explique decisões de Banco de Dados de forma didática, considerando o conhecimento inicial de SQL descrito no roteiro.
- Mantenha modelos, esquema relacional, DDL, gerador e consultas coerentes entre si.
- Registre decisões nos arquivos do projeto; não dependa do histórico de outros chats.
- Ao concluir uma etapa, atualize STATUS.md com resultados, verificações e próximo passo.
- Ao alternar computadores, confira git status antes de atualizar o repositório. Preserve alterações locais e peça orientação diante de conflitos que dependam de decisões do aluno.
- Nunca registre credenciais, tokens ou senhas no repositório.
- Não execute git push --force nem descarte trabalho para resolver sincronização.
